# CodeMaster – E-Learning Web Application

CodeMaster is an ASP.NET Web Forms e-learning platform developed as a team academic project. The application provides separate student and administrator functionality for managing courses, learning content, quizzes, users, and student progress.

## Features

- User registration and login
- Student and administrator roles
- Course catalog and course management
- Student dashboard
- Learning modules and materials
- Quiz system and quiz results
- User management for administrators
- Course and quiz administration
- SQL Server database integration
- Responsive web interface

## Technologies & Concepts

- C#
- ASP.NET Web Forms
- SQL Server / LocalDB
- HTML
- CSS
- Bootstrap
- JavaScript
- ADO.NET
- Relational database design
- Role-based functionality

## Database

The application uses a relational database containing entities for:

- Users
- Courses
- Modules
- Learning materials
- Quizzes
- Questions
- Quiz attempts

The repository includes the SQL schema and sample data required for the application's database structure.
